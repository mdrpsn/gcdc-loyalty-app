# UI snapshots

Screenshots of the local app as it appeared on October 4, 2026, with the `#dc6c3a` accent. All names, contact details, sessions, attendance, and rewards shown are synthetic sample data in an isolated database.

- `01`–`16`: desktop captures at 1440 px wide, including sign-in, member pages, and organizer workflows.
- `17`–`21`: full-page mobile captures at 390 px wide. The member navigation is fixed, so it appears partway down these stitched images.
- `22`–`26`: mobile viewport captures at 390 × 844 px, showing the navigation in its normal on-screen position.
- `27`–`28`: desktop and mobile email-first signup captures.
- `29`–`30`: admin pending and declined approval views for signed-up players.
- `31`: mobile admin approval queue at 390 px wide.
- `32`–`33`: desktop captures of member attendance submission and pending history.
- `34`–`35`: desktop captures of the admin Approved and All filters.
- `36`: organizer search showing the signup requirement for a new player.
- `37`: mobile check-your-email confirmation.
- `38`–`39`: mobile and desktop verified-email profile completion.

The PNG filenames identify each screen. Captures use synthetic data and reflect the current working-tree UI, including the local redesign changes. The first 26 captures predate the attendance approval workflow; the newer captures show that flow.
